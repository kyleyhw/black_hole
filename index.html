What this is

Every pixel of this image is computed by numerically integrating a null geodesic of the Kerr metric backwards from the camera — no approximations to the light bending, frame dragging, or disk kinematics. The metric is used in Kerr–Schild (Cartesian) form, which is horizon-penetrating and axis-regular:

gμν = ημν + f lμ lν,  f = 2Mr³/(r⁴ + a²z²)

Rays follow Hamilton's equations for H = ½ gμν(x) pμ pν = 0 integrated with RK4 and adaptive steps; conserved E, Lz and H ≈ 0 monitor the integration live (see the debug views).

The accretion disk is matter on circular equatorial geodesics; its color and brightness use the exact redshift factor

g = 1 / [ ut (1 − Ω λ) ],  λ = Lz/E

which packages gravitational redshift, orbital Doppler beaming (intensity ∝ g⁴) and frame dragging in one expression. The inner edge sits at the innermost stable circular orbit rISCO(a) and moves as you change the spin.

Throughout, geometrized units are used (G = c = 1), so lengths are multiples of the mass M and a = J/M is the spin (angular momentum per unit mass). The panel's Units & notation popup (ⓘ at the top of the controls) defines every symbol.

Physics, numerics, and validation are documented in the repository.
